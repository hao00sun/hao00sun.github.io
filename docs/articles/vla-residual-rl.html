03 / 学习笔记 · VLA 后训练

VLA 残差强化学习：改动作、控制噪声和微调有什么区别？

先问修改发生在哪里，再问更新谁、用什么信号学。不同维度，不必挤进同一个分类。

旺仔 · 2026 年 11 月 17 日 · 机制梳理 / 初稿
本文路线01 三个比较维度02 改输出动作03 控制生成噪声04 更新模型参数05 数据与评估参考资料

“残差”主要描述策略组合方式，“微调”描述参数更新，“强化学习”描述学习信号与优化方式。它们可以交叉，不能只按名字判断是否属于同一类方法。

本文是概念对照与工程推演，不是个人复现成绩报告，也不将一种方法在 π₀ 上的结果直接推广到 π₀.₅。

01 / 用三个问题建立比较表

路线接入位置常见更新对象需先确认
动作残差基策略输出之后残差策略；基模常冻结动作语义与可组合性
生成噪声引导生成过程的初始噪声噪声策略；基模冻结基模是否暴露噪声接口
参数微调模型内部全参、部分层或适配参数训练目标与梯度路径

表中是典型配置，不是互斥的算法定义。无论选择哪种路线，都还要补一列：学习来自专家动作、环境奖励，还是其他反馈。

02 / 动作残差：对名义动作作修正

a_base = π_base(o)
Δa = π_res(o, a_base)
a_final = a_base + α × Δa

基策略给出名义动作，小策略学习修正量。经典残差强化学习将已有控制信号与 RL 学到的残差组合；这种思想也可以用于已有学习策略，但具体适配仍需验证。参见 Residual Reinforcement Learning for Robot Control。

上式只适用于可以在同一空间组合的动作。位置和速度不能直接相加；旋转需要与表示一致的组合规则；归一化量和真实单位也不能混用。最终限幅和控制处理需要被纳入训练与部署的一致执行链。

若标签是 专家动作 − 基策略动作，用监督损失训练残差，这是 Residual BC。若通过交互奖励更新残差，才是 Residual RL。前者需要同一观测下语义对齐的专家标签，后者需要合适的交互或离线 RL 数据与学习算法。

“基模低频、残差高频”是一种设计选择。它要求新鲜观测、明确的动作块调度与时延控制，并不会因为加了一个小网络就自动实现。

03 / 噪声引导：改变生成过程的输入

w = π_noise(o)
a = F_frozen(o, w)

以 DSRL 为例，策略学习选择生成器的初始噪声，冻结的扩散或 flow 策略再将它变成动作。修改位置在生成过程之前，和在输出动作上加一个修正量不同。噪声维度也不一定比动作维度小。参见 DSRL 项目页。

冻结基模权重并不意味着部署时不需要基模。每次选择噪声后，仍需要调用生成器。基模必须提供对应接口，而且所生成行为要能被这种控制有效引导；不能把它当成任意 VLA 的通用开关。

DSRL 的不同训练变体还需要区分：噪声空间 SAC 使用与噪声动作对应的经验；Noise Aliasing 路线引入动作价值学习，再将生成动作的价值传递到噪声价值估计。动作 Critic 与噪声 Critic 是两类函数，不能和 SAC 常见的双 Q 混为一谈。细节见 论文的 Noise Aliasing 部分。

04 / 微调：改变模型本身

微调回答的是“哪些参数会变”。全参数、部分模块或 LoRA，都需要结合具体模型实现判断。学习目标可以是模仿学习，也可以是适配该策略形式的 RL 目标，因此“微调”和“RL”不是二选一。

以生成动作的 VLA 为例，要确认动作头的生成形式、训练目标、可训练参数与推理过程。不能把一个输出动作块的接口，直接当成 PPO 所需的可计算动作 log probability 接口。openpi 官方仓库区分了 flow 与自回归模型，具体支持情况应以选定代码版本和模型配置为准。

选择微调时，还需评估资源成本、旧能力是否退化，以及检查点能否完整恢复。冻结大部分参数可以改变训练成本，却不自动保证新任务有效或旧任务不退化。

05 / 数据条件往往先决定可行路线

只有观测与专家动作，可以先讨论监督学习。要学习动作价值，通常还需要可对齐的实际动作、奖励或可计算奖励的信息、下一观测，以及终止和截断语义。

遥操数据没有噪声标签，不能直接伪装成噪声策略的交互记录；缺少残差标签，也不能随意用最终动作减掉另一个状态下的基动作。若借助动作 Critic 利用这类数据，还要处理候选动作超出数据覆盖后的估值误差。

做比较时固定基模、初态、指令、对象和评估规则。除了成功率，也报告人工接管、安全事件、推理延迟、训练成本与旧任务回归。跑通训练链路是工程进展，任务收益需要另外证明。
